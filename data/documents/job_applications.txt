==================================================
WORKFLOW DEBUGGING EXAMPLES
==================================================

Example 1 — AI output was not valid structured JSON:
- Problem:
  An AI node returned normal text instead of the structured JSON
  required by downstream workflow steps.
- Approach:
  Improved the prompt and instructions, explicitly defined the
  required JSON structure, added examples, and tested the output
  against downstream nodes.
- Result:
  The AI output became more predictable and usable by subsequent
  automation steps.

Example 2 — API limits / batch processing:
- Problem:
  Processing too many records at once caused inconsistent API
  behaviour and limits.
- Approach:
  Reduced the batch size, tested progressively larger batches, and
  identified a stable processing range.
- Result:
  Workflow became more reliable while still processing records
  efficiently.

Example 3 — Bulk outreach workflow:
- Workflow:
  Loop Over Items → HTTP Request → Wait
- Problem:
  Sending too many requests together created reliability issues.
- Approach:
  Reduced the batch size and introduced controlled waiting between
  requests.
- Result:
  Outreach processing became more stable and controlled.
