AI GTM Automation — Debugging & Troubleshooting Experience

Documented hands-on debugging examples:

1. AI output formatting:
An AI node returned output that was not valid JSON for the downstream workflow. I improved the prompt with tighter formatting instructions and examples, then tested the downstream nodes again.

2. API batch-size handling:
A company-research workflow showed inconsistent API behavior when processing around 20 companies at once. I reduced the batch size progressively and found a smaller stable processing range, around 5–6 companies.

3. Clay batch processing:
A Clay enrichment workflow initially processed a batch of 17 records. I reduced the batch size to 5 and added a Wait step to make processing more controlled.

4. Bulk outreach processing:
For bulk outreach, I used Loop Over Items → HTTP Request → Wait. I reduced the processing batch size and controlled the waiting between requests to handle API processing more reliably.

Interview positioning:
These examples demonstrate hands-on debugging of AI output formatting, API limits/batching, workflow timing, and downstream automation behavior. Describe them as project debugging experience, not as production incidents or organizational impact.
